# Computer Visioin Analysis

A computer vision project in Python for detecting dominant colors, shapes, and objects (vehicles) in images, using **OpenCV**, **scikit-learn (KMeans)**, and **YOLOv8 (Ultralytics)**.

## Features

The project is organized into three main areas:

### 🎨 Color detection (`detector/`)
- **`detect.py`** — Detects the dominant colors of an image using KMeans clustering (5 clusters) in the HSV color space, and maps each color to the closest name in the CSS3 palette (via `webcolors`), showing the percentage of each color in the image.
- **`dominant.py`** — Detects predefined colors (red, green, blue, yellow, orange, purple, pink, white, black, gray, brown) using HSV range masks, calculating the percentage of pixels for each color and reporting the dominant one.

### 🚗 Computer vision with OpenCV (`use_opencv/`)
- **`main.py`** — Detects the color red in real time via webcam, drawing a rectangle around the detected areas.
- **`histogram_rgb.py`** — Generates the RGB histogram of an image using Matplotlib.
- **`car_see.py`** — Detects edges and contours of objects (e.g., vehicles) in an image using Canny Edge Detection.
- **`found_car.py`** — Detects and classifies geometric shapes (triangle, square, rectangle, circle, polygon) from the image's contours.

### 🤖 Object detection with YOLOv8 (`use_yolo/`)
- **`yolo.py`** — Detects objects in an image using the `yolov8s.pt` model and saves the annotated result.
- **`count_vehicle.py`** — Counts the number of vehicles (car, motorcycle, bus, truck, airplane) detected in an image.
- **`yolo_transit.py`** — Detects objects in a traffic scene using the `yolov8m.pt` model.

## Project structure

```
color_detector/
├── detector/
│   ├── detect.py          # Dominant colors with KMeans + webcolors
│   └── dominant.py        # Colors via predefined HSV ranges
├── use_opencv/
│   ├── main.py             # Red color detection via webcam
│   ├── histogram_rgb.py    # RGB histogram
│   ├── car_see.py          # Edge/contour detection
│   └── found_car.py        # Geometric shape classification

```

## Requirements

- Python 3.9+
- All dependencies are listed in `requirements.txt`:
  - `opencv-python`
  - `numpy`
  - `scikit-learn`
  - `matplotlib`
  - `ultralytics` (required by the scripts in `use_yolo/`)
  - `webcolors` (required by the scripts in `detector/`)

## Installation

```bash
git clone https://github.com/cdantass/Computer_vision_analysis.git
cd Computer_vision_analysis/color_detector
pip install -r requirements.txt
```

## Usage

Each script works independently. Adjust the input image path inside the file if needed, then run:

```bash
# Dominant color detection (KMeans + CSS3 names)
python detector/detect.py

# Predefined color detection via HSV ranges
python detector/dominant.py

# Red color detection via webcam
python use_opencv/main.py

# RGB histogram of an image
python use_opencv/histogram_rgb.py

# Edge/contour detection
python use_opencv/car_see.py

# Geometric shape classification
python use_opencv/found_car.py

# Object detection with YOLOv8
python use_yolo/yolo.py

# Vehicle counting
python use_yolo/count_vehicle.py

# Detection in a traffic scene
python use_yolo/yolo_transit.py
```

> **Note:** some scripts reference specific images (e.g., `praia.jpg`, `img/vehicle.jpg`, `img/airplane.jpg`, `img/transit.jpg`, `img/lua.jpg`). Make sure the image file exists at the indicated path before running the script, or replace it with the path to your own image.
